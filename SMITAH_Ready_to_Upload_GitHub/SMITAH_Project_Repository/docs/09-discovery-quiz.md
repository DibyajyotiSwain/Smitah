# 9. Sample Discovery Quiz

This is a conceptual preference questionnaire, not a psychological test or mental-health assessment.

## Q1. Which activity would you most like to explore?
- Drawing, painting or design
- Writing, journaling or storytelling
- Music, rhythm or movement
- Nature, places and virtual exploration
- Learning a practical skill

## Q2. How would you prefer to spend a short break?
- Try a creative prompt
- Do a quiet reflection or breathing exercise
- Learn something new
- Explore an interesting place or topic
- Connect with a group activity

## Q3. What kind of guidance do you prefer?
- Clear step-by-step guide
- Flexible prompt with room to experiment
- Short video or visual example
- Group challenge
- Independent exploration

## Q4. How long would you usually like an activity to take?
- 5 minutes
- 10–15 minutes
- 20–30 minutes
- It depends on the activity

## Q5. How would you like to share your progress?
- Keep it private
- Share with selected people
- Share with the community
- Decide separately for each activity

## Example preference mapping
| Preference | Possible suggestions |
|---|---|
| Art and design | Drawing prompts, visual challenges |
| Writing | Journaling prompts, storytelling |
| Music and movement | Rhythm exploration, movement activities |
| Nature and exploration | Virtual travel themes |
| Learning | Skill-building challenges |
| Quiet activities | Optional reflection and mindfulness |
| Group activities | Community challenges |

Users should be able to edit preferences, skip questions and control whether answers are saved.
