# Project Disclaimer

SMITAH is a concept-stage proposal for a creative well-being platform. The name is inspired by the Sanskrit word *Smita (स्मित)*, meaning “smile”.

This repository contains project explanations, proposed features, sample quiz questions, user journeys, storyboards and diagrams. It does **not** contain a working application. The described features have not been implemented or tested.

SMITAH is not a medical, psychological, diagnostic, counselling or emergency service. Any future professional-support feature would require clearly defined qualifications, safeguarding, privacy and referral arrangements.

Do not claim improved happiness, reduced stress or improved mental health without appropriate research and evidence.
