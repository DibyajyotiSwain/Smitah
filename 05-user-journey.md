# 5. Proposed User Journey

1. **Discover:** user reads about SMITAH and its four pillars.
2. **Create a profile:** user chooses optional interests and interface preferences.
3. **Discovery Quiz:** user answers non-clinical questions about interests and preferred activity styles.
4. **Explore dashboard:** user sees activity categories and optional suggestions.
5. **Choose an activity:** creative prompt, mindfulness, skill-building or community activity.
6. **Explore and connect:** user may explore a virtual experience, view information about facilitated sessions or share a daily moment.
7. **Reflect and provide feedback:** user can optionally reflect and submit a suggestion.
8. **Refine:** feedback is reviewed and may inform future design updates.

Participation should be optional. Users can skip questions, change preferences and control sharing. The concept should not make clinical or guaranteed happiness claims.
