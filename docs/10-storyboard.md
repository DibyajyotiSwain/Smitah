# 10. Primary Storyboard — Conceptual User Experience

This is a proposed journey, not a record of a tested or implemented app.

| Frame | Scene | User action | Intended response |
|---|---|---|---|
| 1. Welcome | SMITAH introduction | Reads purpose and continues | Explains four pillars |
| 2. Profile | Profile creation | Enters basic details and interests | Shows customisation choices |
| 3. Discovery | Preference quiz | Answers optional questions | Summarises selected interests |
| 4. Dashboard | Creative dashboard | Browses activity cards | Displays activity categories |
| 5. Activity | Creative prompt | Selects a prompt | Shows instructions |
| 6. Explore | Virtual adventure | Selects a destination or theme | Presents guided exploration concept |
| 7. Community | Daily moments | Chooses whether to share | Shows privacy choices |
| 8. Reflection | Feedback | Rates or comments | Records feedback for review |

## Narration
A user learns what SMITAH offers, creates a profile, chooses interests and completes an optional preference quiz. The proposed dashboard presents activities. The user chooses at their own pace, may explore a virtual experience or community feature, and can finish by reflecting or sharing feedback.
